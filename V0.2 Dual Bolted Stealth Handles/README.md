## Voron 0.2 Dual Bolted Stealth Handles
:warning: Preloading of M3 nuts is needed!  
:warning: Compatible with 3mm panels only!

<img width="800" alt="image" src="https://github.com/user-attachments/assets/2cb1e331-e99f-475f-ae31-2c6a5db11fdb" />

This is a remix of the [Voron V0 Stealth Handles](https://www.printables.com/model/481575-voron-v0-stealth-handles) by Maple Leaf Makers.  
Changes the bolt count and length to 2 and 16 mm respectively.

## BOM

|Description| QTY |Remarks|
|:-:|:-:|:-|
|M3x16 Bolt|4|BHCS or SHCS|
|M3 Nut|4||
|**Stealth Handle - Dual Bolted**|2|1. Use brims if necessary<br>2. Your printer must be tuned to print at 45 degrees|

***Strong** ➜ Printed Part<br><br>
The STL files can be found [here](https://github.com/Agsikap3D/Voron-0.2-Mods/blob/main/V0.2%20Dual%20Bolted%20Stealth%20Handles/CAD/Dual_Bolted_Stealth_Handle.stl).  
Recommended print settings unless specified :

- Voron parts print settings
- No supports  
- STL files are already oriented for printing  

## Assembly Notes 
1. Preloading is necessary for this mod. So plan ahead!  

<img width="600" alt="image" src="https://github.com/user-attachments/assets/63e91cd2-ee8f-4990-a27f-c2c0493c1dcd" />

2. Replaces existing top middle clip of left and right side panels.  
3. Install the handles in the COG of the printer. (Usually off-centered the printer towards the back)
4. **Overall Width Increase**: 242.1mm ➜ 270.8mm (28.7mm increase).
