## Assembly Notes
<img width="800" alt="image" src="https://github.com/user-attachments/assets/4d7274df-f9e5-4bbe-9dd9-842fc33f7917" />

1. You could use the other side by using the mirror command to the body in slicer.
2. The thermistor fit is slightly tight. If it is too tight, you can ream the hole using a Ø3mm drill bit.
3. If the pre-supported print doesn't work due to tolerances, use the regular STL and print as you desired.
