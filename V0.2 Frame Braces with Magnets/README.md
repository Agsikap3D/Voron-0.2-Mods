## Voron 0.2 Frame Braces with Magnet
:warning: Preloading of M3 nuts is needed!

<img width="800" alt="image" src="https://github.com/user-attachments/assets/a25a9541-220f-4b7a-a604-46c49d20a6e0" />

This is a remix of the [Voron 0 Frame Bracing](https://www.printables.com/model/854181-voron-v0-01-02-r1-frame-bracing-hex-edition-update) by driftrotor.  
Integrates the door magnets to the frame bracing.<br><br>
<img width="150" alt="image" src="https://github.com/user-attachments/assets/0fc59e13-5d92-435a-8d2b-c260620b55db" />

#### Current available designs:  
- Aluminum extrusion pattern    
- Hex pattern

## Assembly Notes
1. Preloading is necessary for this mod. So plan ahead!
   
<img width="800" alt="image" src="https://github.com/user-attachments/assets/57af790d-473f-439f-b232-223b791c10b2" />

2. Replaces the bottom stock magnetic door latch.
<img width="200" alt="image" src="https://github.com/user-attachments/assets/16b12d7e-7c49-49b1-8851-012f973f18a2" />

3. You might need to use super glue to secure the magnet if it is too lose.
4. You can refer to the [STP file](https://github.com/Agsikap3D/Voron-0.2-Mods/blob/main/V0.2%20Frame%20Braces%20with%20Magnets/CAD/Frame_Braces_with_Magnets.stp) for more information.
